# Wood-Fired Margherita

[![make.fun · food-picture-01](https://make.fun/badge/food-picture-01.svg)](https://make.fun/bounty/food-picture-01)

A wood-fired margherita pizza, fresh from the oven: bubbling mozzarella,
charred leopard-spotted crust, fresh basil, olive oil, and steam rising off
a rustic wooden board. Shot overhead so the whole dish fills the frame.

## Run it

```sh
node main.ts
```

This validates `entry.jpg` (whole JPEG, ≤ 1 MiB, ≤ 1024×1024) and copies it
to `/output/entry.png`.

## Files

- `entry.jpg` — the entry image, 1024×1024 JPEG
- `main.ts` — the entry program
